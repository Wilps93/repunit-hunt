# Методология: как считать константу ЛПВ по обобщённым репьюнитным простым

Извлечено из `analysis.py` — не пересказ, а описание того, что исполняется.
Каждый пункт помечен тегом, под которым соответствующее число печатается в
`results.txt` и сверяется `check_numbers.py`.

Работает без знания недокументированных границ поиска. Даёт точные интервалы
там, где они точны, и честно симулированные — там, где точных нет.

---

## 0. Обозначения и границы применимости

| Символ | Смысл |
|---|---|
| `b` | основание, `2 ≤ b`, **не точная степень** (иначе `R_b(n)` факторизуется алгебраически) |
| `n` | индекс; `R_b(n) = (bⁿ−1)/(b−1)` может быть простым **только при простом n** |
| `t` | `t = ln n` — рабочая ось. Всё дальнейшее живёт в логарифмах |
| `t₀` | `t₀ = ln n_min`, наименьший известный индекс. **Начало отсчёта, а не событие** |
| `N_b` | число событий строго правее `t₀` = (число известных индексов) − 1 |
| `D_b` | `D_b = t_{N_b} − t₀ = ln n_max − ln n_min` |
| `κ` | оцениваемая константа. ЛПВ: `κ = e^γ = 1,781072…` |
| `λ_b` | интенсивность процесса по основанию b: `λ_b = κ / ln b` |
| `B`, `M`, `S` | число оснований; `M = Σ N_b`; `S = Σ D_b / ln b` |

> **Главная ловушка.** `D_b` — разность **логарифмов**, а не индексов.
> Для `b = 2`: `D₂ = ln 136 279 841 − ln 2 = 18,0371`. Если взять
> `n_max − n_min = 136 279 839`, величина завышается в 7,6 млн раз, и оценка
> уходит с 1,838 в ~10⁻⁷.

**Модель.** Индексы образуют однородный пуассоновский точечный процесс на оси
`t` с интенсивностью `λ_b = κ/ln b`. Это рабочее допущение, а не теорема: даже
для обычных простых пуассоновость доказана лишь условно.

---

## 1. Достаточные статистики  `[Табл. 1]`

По каждому основанию нужны ровно три числа: `N_b`, `n_min`, `n_max`.
Полные списки индексов нужны только для §5 (усечение) и §7 (регрессия).

```python
t   = log(idx)          # idx — отсортированный список известных индексов
N   = len(idx) - 1
t0  = t[0]
D   = t[-1] - t[0]
expo = D / log(b)       # вклад основания в S
```

Отбор оснований: все не-точные-степени в объявленном диапазоне. Основание
остаётся в выборке, если у него `N_b ≥ min_events` (по умолчанию 1; в таблице
усечения используется 2 — **правило обязано быть объявлено**, оно меняет
результат).

## 2. Оценки по одному основанию  `[Табл. 5]`

```python
G_end   = D / (N * log(b))          # концевая форма
G_ols   = polyfit(arange(N+1), t, 1)[0] / log(b)   # наклон МНК t_k на k, k = 0..N
kappa_hat   = N     * log(b) / D    # ММП, смещена вверх в N/(N−1) раз
kappa_tilde = (N-1) * log(b) / D    # несмещена точно
```

**Что здесь несмещено, а что нет** — это главный отрицательный результат:

- `G_end` и `G_ols` несмещены **точно**. Распространённое подозрение о смещении
  из-за правого цензурирования **неверно**.
- Смещена только обратная величина `κ̂ = 1/Ĝ`, в `N/(N−1)` раз, и это
  неравенство Йенсена, а не цензурирование.
- Несмещённые `κ` и `1/κ` не могут быть взаимно обратными: несмещённая пара —
  `(Ĝ_b, κ̃_b)`, причём `κ̃_b ≠ 1/Ĝ_b`.

Точный доверительный интервал (схема A) и PIT-квантиль:

```python
lo, hi = gamma.ppf(0.025, N) / expo,  gamma.ppf(0.975, N) / expo
pit    = gamma.cdf(KAPPA_LPW * expo, N)
```

**Не интерпретируйте порядок оснований между собой.** Формы оценки расходятся
до 29,5 % (b = 18), при медианном отклонении от `e^−γ` в 17,6 %. У b = 18 и
b = 13 выбор формы весит больше, чем всё их отклонение от ЛПВ: b = 18 переезжает
с 3-го места на 10-е из 15 при одной лишь смене формы. Ярлык «удачливости»
описывает выбор оценки, а не свойства простых.

## 3. Две схемы наблюдения — здесь и лежит вся суть  `[§5.2]`

### Схема A — «до N-го события» (обратная выборка)

Наблюдаем, пока не наберём `N_b` событий. Тогда `D_b ~ Gamma(N_b, λ_b)`,
и `κS ~ Gamma(M, 1)` — точный пивот.

```python
kappa_A = (M - 1) / S
lo, hi  = gamma.ppf(0.025, M) / S,  gamma.ppf(0.975, M) / S
p       = 2 * min(gamma.cdf(KAPPA_LPW * S, M), gamma.sf(KAPPA_LPW * S, M))
```

### Схема B — фиксированный фронт (так данные и получены)

Поиск покрыл `(t₀, ln L_b]` целиком; `N_b` — случайная величина, фронт `L_b`
фиксирован. При фиксированном `N_b` величина `D_b` информативна о фронте, а не
об интенсивности, — правдоподобие схемы A перестаёт быть правдоподобием.

Пусть `W_b = ln L_b − t₀` и `δ_b = ln L_b − t_{N_b}` (при `N_b = 0`: `δ_b = W_b`).
Тогда `δ_b` — экспоненциальная величина, **усечённая** на `W_b`:

```
Pr(δ_b > x) = e^(−λ_b x)   при 0 ≤ x < W_b
Pr(δ_b = W_b) = e^(−λ_b W_b)          ← атом, а не значение хвоста
E[δ_b] = (1 − e^(−λ_b W_b)) / λ_b     ← НЕ 1/λ_b
```

Ссылки на «отсутствие последействия» здесь **недостаточно**: у процесса нет
событий левее `t₀`, поэтому `δ_b ≤ W_b` по построению.

Полная экспозиция `S_full = S + Σ δ_b/ln b = Σ W_b/ln b` **детерминирована**,
и `κ·S_full = Σ λ_b W_b = E[M]` — тождество моментов. Отсюда

```python
kappa_B = (M - B) / S
```

потому что `E[κ Σ δ_b/ln b] = B − Σ e^(−λ_b W_b)`.

**Оценка несмещена с точностью до отбрасываемого остатка,** а не абсолютно.
Остаток — ожидаемое число оснований без единой находки; при `λ_b W_b ≈ N_b ≥ 7`
он меньше `3·10⁻³` против `B = 15`, то есть 0,02 %. Симуляция даёт ровно это.

> **Чего делать нельзя.** Не подставляйте `W_b = ln n_max − t₀`. Тогда `δ_b = 0`,
> и вы получаете схему A при m = 0, то есть `M/S`. Смысл `(M−B)/S` именно в том,
> что **`L_b` знать не нужно** — он в формулу не входит.

### Цена выбора — и почему её не снять

`(M−1)/S` и `(M−B)/S` — функции **одних и тех же** достаточных статистик
`(N_b, D_b)`. Никакая обработка данных не скажет, какая верна: выбор определяется
тем, как данные собирались. Цена — 7 %, вдвое больше остаточного разрыва с ЛПВ.

Обход через «заведомо несмещённые куски» не работает: `κ̃_b` по одному основанию
несмещена при обеих схемах (с той же экспоненциально малой поправкой), но
взвешенное среднее с обратно-дисперсионными весами даёт при схеме B смещение
+7,5 % — веса сами случайны и коррелируют с оценками.

Отсюда единственный радикальный выход: **публиковать фронты поиска `L_b`**.

## 4. Симуляция схемы B  `[Табл. 3, Табл. 4]`

Симулируется **весь процесс**, а не только `δ_b`:

```python
for bd in bases:
    lam = kappa / bd.lnb
    W   = frontier_rule(bd, lam)        # ширина окна
    n   = poisson(lam * W)              # число находок — случайно
    n   = resample_while(n < 1)         # у каждого основания есть находка
    u   = uniform(0, 1)
    D   = W * u**(1/n)                  # максимум n равномерных на (0, W]
    M  += n
    S  += D / bd.lnb
```

Правила расположения фронта задаются через `W_b` и **обязаны быть выписаны**:

| правило | `W_b` |
|---|---|
| `E[#] = наблюдённое` | `N_b / λ_b` |
| `+s средних интервалов` | `(N_b + s) / λ_b` |
| `в c раз дальше по t` | `c · D_b` |
| случайное | `(N_b/λ_b) · U`, `U ~ Unif(0,7; 1,8)`, своё у каждого основания и реализации |

Доверительный интервал схемы B — инверсией: для сетки `κ` симулируется схема B,
ищутся `κ`, при которых наблюдённая статистика попадает на квантили 0,025 и
0,975 симулированного распределения.

**Что показывает калибровка.** Номинальный 5 % критерий при схеме B отвергает
верную гипотезу в 16,2 % случаев (разброс по пяти зёрнам 0,162–0,169) —
заявленная точность интервалов завышена примерно втрое.

## 5. Однородность оснований  `[§5.3]`

```python
kappa_hat = M / S
Lambda    = 2 * sum(N_b * log(kappa_hat_b / kappa_hat))   # ~ chi2(B-1)
```

**Неотвержение информативно ровно настолько, насколько мощен критерий.**
Мощности 80 % критерий достигает лишь при коэффициенте вариации `κ_b` около
0,34. Поэтому корректный вывод — «базозависимые частоты данными **не
требуются**», а не «их не существует».

## 6. Мощность  `[Табл. 7, §6]`

Против `κ = r·e^γ` на уровне α, в замкнутой форме:

```python
lo, hi = gamma.ppf(a/2, M), gamma.ppf(1-a/2, M)
power  = gamma.cdf(lo*r, M) + gamma.sf(hi*r, M)
```

| выборка | отклонение, различимое с мощностью 80 % |
|---|---|
| только Мерсенн, M = 51 | ≥ 49,8 % |
| объединение 15 оснований, M = 218 | ≥ 21,2 % |
| для 10 % нужно | M ≈ 875 |
| для 5 % нужно | M ≈ 3319 |

Удвоение всех пятнадцати фронтов даёт ~9,6 дополнительных событий. Недостающие
657 событий — это ~68 удвоений, то есть рост фронтов в `3,3·10²⁰` раз.

**Правило чтения литературы.** Сообщение «данные согласуются с ЛПВ с точностью
до нескольких процентов» не есть свидетельство в пользу ЛПВ на уровне нескольких
процентов: оно совместимо с константой, ошибочной в полтора раза.

## 8. Ошибка того же рода в ином обличье  `[§7]`

Регрессия счётной функции на `t` по точкам событий даёт на вид значимый
свободный член. Он артефакт обусловливания, и тому три подтверждения:

- остатки кумулятивного счёта автокоррелированы (`ρ₁ = 0,825`); Ньюи — Уэста с
  восемью лагами увеличивает стандартную ошибку в 1,64 раза;
- корректная нулевая модель удерживает `[t₀, T]` фиксированным и обусловливается
  `N−1` событиями — это `N−1` равномерных точек на `(t₀, T]`;
- **бутстрэп по точкам событий не спасает**: он воспроизводит изменчивость
  внутри реализованной конфигурации и не может восстановить изменчивость
  породившего её процесса. Корректный нулевой закон в 6,5 раза шире бутстрэпного.

Оценивание `λ` по последнему событию обращает остаток в нуль на обоих концах —
траектория становится аналогом броуновского моста, у которого отрицательная
экскурсия в середине возникает сама собой.

## 10. Как воспроизвести

```bash
python3 analysis.py        # все числа -> results.txt, рисунки -> figs/
python3 check_numbers.py   # сверка статьи с results.txt
python3 check_stability.py # устойчивость к зерну
bash validate.sh --full    # всё разом, включая независимый пересчёт данных
```

Зерно генератора зафиксировано, поэтому величины Монте-Карло воспроизводятся
побитово. Данные включены в репозиторий — сеть для воспроизведения не нужна.
