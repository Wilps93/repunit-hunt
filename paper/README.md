# Материалы к статье о константе Ленстры — Померанса — Вагстаффа

Воспроизводимый анализ к работе «Схема наблюдения в статистике обобщённых
репьюнитных простых: калибровка объединённой проверки константы
Ленстры — Померанса — Вагстаффа».

## Быстрый старт

```bash
# 1. Данные (уже лежат в data/, шаг нужен только для обновления)
bash fetch_data.sh          # b-файлы OEIS, основной набор b <= 20
bash fetch_extra.sh         # b = 21..26, проверка границы отбора

# 2. Все числа статьи + рисунки  (несколько минут)
python3 analysis.py         # -> results.txt, figs/*.pdf
python3 analysis.py --fast  # сокращённое Монте-Карло, для проверки

# 3. Статья
bash build_paper.sh         # -> paper.pdf
```

## Полная валидация

Один прогон вместо десяти команд:

```bash
bash validate.sh          # прогоны 1-4, около минуты
bash validate.sh --full   # плюс независимый пересчёт, около десяти минут
```

| Прогон | Что проверяет |
|---|---|
| 1. Чистая комната | всё производное строится заново из `data/` и `paper.tex` |
| 2. Сверка | числа, ГОСТ, данные, самоповтор, типографика, орфография, PDF |
| 3. Устойчивость к зерну | выводы при пяти зёрнах генератора |
| 4. Живые источники | b-файлы OEIS и фронт GIMPS не сдвинулись |
| 5. Независимый пересчёт | `repunit-hunt` заново считает все n < 10⁴ (`--full`) |

Код возврата 0 только если пройдено всё. Отдельные проверки можно звать и по одной:

```bash
python3 check_numbers.py    # 37 чисел статьи против вывода analysis.py
python3 check_gost.py       # 31 проверка по ГОСТ Р 7.0.7-2021
python3 check_method.py     # 33 числа METHOD.md против вывода analysis.py
python3 check_stability.py  # устойчивость к зерну
python3 check_overlap.py    # самоповтор с ранними редакциями
python3 compare_verify.py   # пересчёт против OEIS
```

Зависимости анализа: `numpy`, `scipy`, `matplotlib`.
Сборка статьи: `texlive-latex-recommended`, `texlive-lang-cyrillic`,
`texlive-latex-extra`.

## Что где

| Файл | Назначение |
|---|---|
| `paper.tex`, `paper.pdf` | статья |
| `METHOD.md` | методология в исполняемом виде: извлечена из `analysis.py`, числа сверяются `check_method.py` |
| `analysis.py` | воспроизведение **всех** чисел; каждое помечено тегом `[Табл. N]` / `[§N.N]` |
| `results.txt` | вывод `analysis.py` |
| `check_numbers.py` | сверяет 37 ключевых величин статьи с `results.txt`; код 1 при расхождении |
| `check_gost.py` | 31 проверка по ГОСТ Р 7.0.7-2021 (действует с 01.10.2021); код 1 при нарушении |
| `check_stability.py` | прогоняет анализ при пяти зёрнах; детерминированные величины должны совпасть точно, монте-карловские — остаться в коридоре |
| `check_overlap.py` | самоповтор с ранними редакциями (шинглы по 8 слов) |
| `validate.sh` | оркестратор: все проверки в пяти прогонах |
| `figs/` | четыре рисунка, генерируются `analysis.py` |
| `data/` | b-файлы OEIS, 20 последовательностей |
| `FINDINGS.md` | отчёт: что воспроизвелось, что исправлено |
| `verify_sequences.sh` | независимый сплошной пересчёт последовательностей поисковиком |
| `compare_verify.py` | сверка пересчёта с OEIS, код возврата 1 при расхождении |
| `verify/` | результаты пересчёта и протокол прогона |

Генератор случайных чисел инициализирован фиксированным зерном (`SEED` в
`analysis.py`), поэтому величины Монте-Карло воспроизводятся побитово.

## Независимый пересчёт последовательностей

Сверка с OEIS подтверждает, что перечисленные индексы дают простое, но не
гарантирует **полноты** списка. Пропущенный член сдвинул бы `N_b`, а с ним и
обе объединённые оценки. Поэтому все индексы `n < 10^4` пересчитаны подряд
поисковиком из корня репозитория:

```bash
bash ../paper/build_and_verify.sh                 # собрать repunit-hunt
DC=1.0 bash verify_sequences.sh 10000             # сплошной пересчёт
python3 compare_verify.py                         # сверка с OEIS
```

`DC=1.0` включает сплошной double-check: каждый отрицательный вердикт
пересчитывается вторым, независимым бэкендом. Без этого потерянная находка
(ложное «составное» из-за сбоя FFT) остаётся невидимой — именно так был найден
баг в GWNUM-пути, описанный в `FINDINGS.md`, §4.

Текущий результат: **153 члена подтверждены, лишних 0, пропущенных 0**
по всем двадцати основаниям.
